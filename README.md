# CodeAlpha Task 4 - Basic Chatbot

## Project Overview
This project is a simple rule-based chatbot developed
using Python as part of the CodeAlpha Python Internship.

## Features
- Accepts messages from the user.
- Responds to predefined messages.
- Supports greetings, help, thanks and goodbye.
- Keeps the conversation running using a loop.
- Ends the conversation when the user types "bye".
- Handles empty and unknown messages.

## Concepts Used
- Python functions
- if-elif-else statements
- while loop
- break and continue
- Input and output

## Requirements
- Python 3
- Visual Studio Code (or any Python editor)

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: python main.py
4. Type a message and press Enter.
5. Type "bye" to exit the chatbot.
